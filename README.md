# Bread + Master Ventures

Planning and development workspace for ventures being developed jointly by **Bread** and **Master**.

## Current priorities

### For-profit ventures
- Car wash
- Laundromat
- Vending machines

### Separate nonprofit initiative
- Fathers-focused community and housing programme
- Housing assessment and referral process
- Employment, transportation, food, clothing and family-stability support

## Operating approach

Bread and Master are managing the ventures jointly while they are being developed. Permanent management roles will be assigned later as each venture becomes operational.

The nonprofit initiative must remain legally, financially and operationally separate from the for-profit ventures.

## Repository structure

- `docs/` — master plan, decision rules and idea backlog
- `ventures/car-wash/` — car-wash planning
- `ventures/laundromat/` — laundromat planning
- `ventures/vending/` — vending-machine planning
- `nonprofit/fathers-housing/` — fathers housing/community programme planning

## Security note

Do **not** commit bank details, tax IDs, Social Security numbers, passwords, API keys, personal IDs, client records or other confidential information to this repository.
