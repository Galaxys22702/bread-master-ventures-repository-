## How Bread + Master work

- Bread and Master manage the ventures jointly while they are being developed.
- Permanent management roles are assigned later, based on what each operating business actually needs.
- Every active task should have one temporary owner.
- Major commitments such as debt, leases, investors, ownership changes and major equipment purchases require joint approval.
- Decisions and spending assumptions should be written down.
- Quotes, estimates and actual costs must be labelled clearly.
- Demand should be validated before major purchases.

## Repository workflow

Keep `main` clean and usable. Meaningful changes should normally be made on a branch and reviewed before merging.

Use short, descriptive file names in lowercase with hyphens, for example:

```text
startup-costs.md
location-research.md
decision-log.md
```

## Security

This is a **public repository**. Do **not** commit bank details, tax IDs, Social Security numbers, passwords, API keys, personal IDs, client records, private contracts, private addresses or other confidential information.

See [SECURITY.md](SECURITY.md) before adding operational data.
